Automatización

Crea una automatización personal en la app Atajos de iPhone para que balanc*d registre tus gastos solo, sin que tengas que abrir la app. Este es un ejemplo real: registrar un gasto automáticamente al acercar una tarjeta de pago al iPhone, pero el disparador puede ser cualquier otro (una hora concreta, una ubicación...).

Ver tutorial en vídeo
  1. Abre la app Atajos, ve a la pestaña Automatización y toca el botón "+" de arriba a la derecha para crear una nueva automatización personal.
  2. Como condición, elige "Cartera" → "Cuando toque una tarjeta o un pase de la app Cartera".
  3. Selecciona las tarjetas de pago con las que quieres que se dispare la automatización (puedes marcar una o varias) y toca "Añadir".
  4. Toca "Crear nuevo atajo" para empezar a añadir las acciones. Activa "Notificar cuando se ejecute" si quieres saber que el gasto se ha registrado.
  5. Añade la acción "Obtener contenido de URL" apuntando a https://balancd.es/api/login, método POST, con la cabecera Content-Type: application/json y este cuerpo JSON: 
    {"username": "tu_usuario", "password": "tu_contraseña"}
  6. Debajo, añade "Definir variable" (llámala loginresponse) con el resultado del paso anterior. Después añade "Obtener valor" de la clave token dentro de loginresponse, y guárdalo con otra "Definir variable" llamada token.
  7. Añade una segunda "Obtener contenido de URL", esta vez a https://balancd.es/api/movimientos, método POST, con las cabeceras Content-Type: application/json y Authorization: Bearer seguido de la variable token, y este cuerpo JSON (usa las variables que te ofrezca el disparador de Cartera, como el importe o el nombre de la tarjeta): 
    {"cantidad": Importe, "ingreso": false, "asunto": Nombre, "cuenta": "Tarjeta"}
  8. Guarda la automatización. A partir de ahora, cada vez que acerques una de esas tarjetas, balanc*d registrará el movimiento solo, sin que tengas que hacer nada más.

La cantidad es el único campo obligatorio. El asunto y la cuenta son opcionales — si no indicas cuenta y solo tienes una activa, se usa esa automáticamente.
